# Slider Images

Add your images here using the following filenames:

| File            | Slide    |
|-----------------|----------|
| slide-1.avif    | Slide 1  |
| slide-2.avif    | Slide 2  |
| slide-3.avif    | Slide 3  |
| slide-4.avif    | Slide 4  |
| slide-5.avif    | Slide 5  |

Supported formats: `.avif`, `.jpg`, `.jpeg`, `.png`, `.webp`

If you use a different format, update the `src` attributes in `index.html`
(search for `images/slide-`). The page will fall back to stock photos until
your own images are present.
